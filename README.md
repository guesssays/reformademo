# ReForma — женская фитнес-студия

Веб-сайт студии **ReForma**, созданный на React и размещённый на Netlify.  
Сайт адаптирован под мобильные устройства и оптимизирован для SEO.

---

## 🚀 Стек технологий
- [React](https://react.dev/)  
- [Vite](https://vitejs.dev/) (сборка)  
- [Netlify](https://www.netlify.com/) (хостинг и деплой)  
- [Tailwind CSS](https://tailwindcss.com/) (стили)  

---

## 📂 Структура проекта

project-root/
├── public/ # Статические файлы (favicon, manifest, изображения)
├── src/ # Исходный код
│ ├── components/ # Компоненты React
│ ├── pages/ # Страницы сайта
│ ├── data/ # Контент (тексты, цены, расписание)
│ └── lib/ # Вспомогательные функции
├── index.html # Основной HTML
├── package.json # Зависимости и скрипты
└── netlify.toml # Настройки деплоя на Netlify

## ⚙️ Установка и запуск (для разработчиков)
1. Склонировать проект или распаковать архив:  
   ```bash
   git clone <repo-url>
   cd reforma-fitness


Установить зависимости:

npm install


Запустить в режиме разработки:

npm run dev


Сайт откроется по адресу: http://localhost:5173

Собрать проект для продакшена:

npm run build


Предпросмотр собранной версии:

npm run preview

🌐 Деплой на Netlify

Сайт автоматически разворачивается на Netlify при пуше/загрузке.
Для ручного деплоя:

Выполнить сборку:

npm run build


Загрузить содержимое папки dist/ в Netlify.

🛠️ Переменные окружения

Если нужны ключи/настройки API — они указываются в файле .env:

VITE_API_URL=https://api.example.com

👩‍💻 Инструкция для клиента

Если вы не программист, вот что можно менять самостоятельно:

🔹 Тексты и цены

Файлы лежат в папке:

src/data/


Примеры:

homeData.js — данные для главной страницы

prices.js — цены

aboutData.js — тексты о студии

Откройте нужный файл в текстовом редакторе → измените текст в кавычках → сохраните.

🔹 Изображения

Картинки хранятся в:

public/images/


Чтобы заменить картинку:

Положите новый файл в public/images/ (например, hero.jpg).

В коде/данных замените путь к картинке на /images/hero.jpg.

🔹 Иконка сайта (favicon)

Файлы иконок лежат в public/ (favicon.ico, apple-touch-icon.png и др).

Чтобы заменить — замените эти файлы своими с таким же именем.

🔹 Обновление сайта

Если сайт хостится на Netlify:

Изменения в коде → залить на Netlify через git push или загрузку.

Netlify сам пересоберёт и опубликует сайт.

Если используете локально:

После изменений выполнить:

npm run build


Загрузить содержимое dist/ на хостинг.
